# دليل التشغيل — Echarpe / Glow

> للتشغيل اليومي والطوارئ. الجزء التقني للمطورين في `docs/DEVELOPER.md`.

## 1. الرفع والتحديث (النظام المتفق عليه)

1. **دفعة واحدة:** كل الملفات المتغيرة تترفع مرة واحدة — الرفعات المتتالية
   السريعة بتلغي builds بعضها في GitHub Actions.
2. **استنى العلامة الخضراء** في تبويب Actions قبل أي رفعة تانية
   (~3 دقايق، ممكن يظهر 404 مؤقت أثناء الـ rebuild — طبيعي).
3. **كل تعديل = bump للـ CACHE_NAME** في `sw.js` بتاع التطبيق المتعدّل.
4. على كل جهاز: **اقفل التطبيق وافتحه مرتين** عشان الكاش يتجدد.

> جهاز بيعرض نسخة قديمة؟ 90% كاش: اقفل/افتح مرتين. لو استمر: مسح بيانات
> الموقع من المتصفح، أو من الـ exe امسح مجلد `%APPDATA%\echarpe-pos`.

## 2. ⚠️ مشكلة Brave المعروفة

Brave بيمسح localStorage مع القفل → تسجيل دخول متكرر + ضياع إعدادات الطابعة.
**الحل:** Shields OFF لموقع echarpe.store، أو استخدام الـ exe (الأفضل للكاشير).

## 3. الطباعة والدرج

- الطباعة الصامتة من الـ exe (`echarpe POS Setup 1.0.0.exe`).
- إيصالات المرتب بتتبعت عبر طابور `pos_print_jobs` — الـ exe لازم يكون مفتوح.
- تحديث الـ exe: اقفل وافتح مرتين، أو امسح `%APPDATA%\echarpe-pos`.
- **الدرج:** لو مش بيفتح بالكود جرّب زرار الاختبار — المشكلة الحالية غالبًا
  إعدادات طابعة (بيشتغل في QuickBooks على نفس الجهاز) مش كود.

## 4. Firestore والقواعد

- الداتا كلها في مشروع `customer-feedback-8ac1d`.
- **نشر القواعد:** Firebase Console → Firestore → Rules → لصق محتوى
  `security/firestore-phase2.rules` → Publish. (مش بتتنشر من GitHub!)
- نسخ احتياطي يومي شغال (احتفاظ 7 أيام).

## 7. تشخيص سريع

| العرض | السبب الغالب | التصرف |
|---|---|---|
| نسخة قديمة على جهاز | كاش | افتح/اقفل مرتين → مسح بيانات الموقع |
| شاشة "فشل التحميل" في sales | 404 مؤقت وقت rebuild أو ملف ناقص | استنى العلامة الخضراء وحدّث · اتأكد إن sales-app.js و sales-ui.js اترفعوا مع index.html |
| تسجيل دخول بيضيع (Brave) | مسح localStorage | Shields OFF أو exe |
| إيصال مرتب مش بيطبع | الـ exe مقفول | افتح الـ exe على جهاز الكاشير |
| الكاشير اتمنع من البيع بعد نشر rules | الجهاز مش مسجّل بحساب الفرع | سجّل دخول email/password بتاع الفرع |
| إشعارات مش واصلة | صلاحية الإشعارات / token | فعّل الإشعارات وأعد فتح التطبيق |
