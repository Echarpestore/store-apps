# v46 AR MESH

The imported OBJ is no longer the default.

A new purpose-built browser AR hijab mesh is generated at runtime:
- ellipsoid hood with an oval face opening
- overlapping neck wrap to remove the hard horizontal seam
- front/shoulder drape panel that widens and wraps backward at the sides
- subtle geometric fabric folds
- same MediaPipe transformation, occlusion, lighting and projection pipeline

The old OBJ is still available only for comparison with `?obj=1`.

This is the first version whose geometry is designed specifically for this
try-on pipeline rather than adapting a generic downloaded OBJ.
